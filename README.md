# Pekegno Group – Website

Multi-page marketing website for **Pekegno Group** (Agency, Academy, Business School).

- Pages: Home, Agency, Academy, Business School, About, Contact
- Languages: French and English (starts in the visitor's computer language, French by default)
- Single file: `index.html` contains all pages, styles, scripts and photos. No build step.
- `media/` holds the animated year-in-review video (2018–2025).

## Run it locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. On GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Edit the content
Texts, prices and contact details are inside `index.html`. English translations are in the `DICT` object near the top of the main `<script>`.
